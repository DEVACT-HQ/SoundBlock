# Security

If you find a security problem in SoundBlock, please report it privately, so it can be fixed before anyone can use it against other people. Please don't open a public issue.

- **On GitHub:** on this repository's [Security tab](https://github.com/DEVACT-HQ/SoundBlock/security), select **Report a vulnerability**.
- **By email:** [contact@devact.de](mailto:contact@devact.de)

Please include your SoundBlock version, which you'll find by hovering over the info icon at the top left of the window, and the steps that show the problem.

Fixes go into the latest release only, so please check that version first.

## Staying safe

Only download SoundBlock from this repository's [Releases page](https://github.com/DEVACT-HQ/SoundBlock/releases/latest). If you got it anywhere else, delete it and download it from there.

Every update is signed. SoundBlock checks the signature before it offers a new version, and only installs a file that matches it.
